OPERATION: BIRTHDAY HEIST
========================

VS CODE SETUP
1. Unzip this folder.
2. Open the folder in VS Code.
3. Open index.html in a browser.
   Recommended: install the "Live Server" VS Code extension and choose "Open with Live Server".

FEATURES
- 5 sequential birthday-surprise stages
- Responsive mobile/desktop dark UI
- Native Web Audio API sound effects and birthday melody
- Confetti effects
- Fingerprint scanner, lie detector, runaway abort button
- Candle challenge and touch/mouse scratch card
- Custom name, nickname, letter and signature
- URL-hash shareable configuration (no login/database required)
- Virtual cake with wish + blow-out interaction
- Celebration toolkit

SHARING
Use Customize to personalize the experience, save it, then use "Copy Share Link" on Stage 5.
The configuration is encoded in the URL hash, so the recipient can open the link directly.

NOTE
Because the project is a single self-contained HTML file, it does not need npm, React, Tailwind, external libraries, images, or audio files.
